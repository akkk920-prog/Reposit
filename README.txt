OSINT INFO — Telegram Bot + Mini App

=== Файлы ===
- bot.py          → код Telegram-бота
- index.html      → код Mini App
- hero.jpg        → картинка для главного экрана (скачай отдельно или замени)

=== Как запустить ===

1. Бот:
   - Установи: pip install aiogram
   - Вставь токен от @BotFather в bot.py
   - Укажи URL Mini App в строке WebAppInfo
   - Запусти: python bot.py

2. Mini App:
   - Залей index.html + hero.jpg на любой хостинг (Vercel, Netlify, Cloudflare Pages)
   - В BotFather привяжи этот URL как Web App

3. Картинка hero.jpg:
   - Используй ту, что я сгенерировал ранее (два человека в масках)
   - Или поставь любую свою в стиле OSINT

Важно:
Только открытые источники. Закрытые базы и утечки использовать нельзя.
