# CatUp Telegram Mini App

Полноценный фронтенд для Telegram Mini App по предоставленным макетам.

## Как запустить

1. Загрузите папку на любой хостинг (GitHub Pages, Vercel, Netlify, свой сервер).
2. В BotFather создайте бота → `/newapp` → укажите URL вашего сайта.
3. Откройте Mini App внутри Telegram.

## Возможности

- **Кейсы** — 6 кейсов с реальными шансами, рулетка, демо-режим
- **Апгрейд** — ставка звёзд или NFT против цели, расчёт шанса
- **Краш** — летящая машина + кошка, кэшаут, шанс большого икса ~20%
- **Мины** — сетки 3x3 / 5x5 / 7x7, короны и бомбы
- **Колесо Фортуны** — PvP банк, пропорциональные шансы
- **Кошка** — переход дороги, трафик, 4 уровня сложности
- **Профиль + Пополнение** — Stars (симуляция), GRAM (отключено), NFT через @Avstralua
- Баланс сохраняется в localStorage
- Интеграция Telegram WebApp (тема, expand, openLink)

## Важно

- Платежи Stars требуют бэкенда (createInvoiceLink + openInvoice). Сейчас — симуляция.
- Для продакшена добавьте серверную проверку ставок и provably fair.
- NFT-подарки обрабатываются ботом @Avstralua (как в макете).

## Файлы

- `index.html` — структура
- `styles.css` — стили в точности под макеты
- `app.js` — вся логика игр
