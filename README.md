# CatUp — Telegram Mini App

Готовый фронтенд для Telegram Mini App (CatUp).

## Что уже сделано

- Главное меню с реальными картинками (Кейсы, Краш, Мины и т.д.)
- Кейсы с картинками и шансами
- Краш:
  - Реальная машина с котом
  - Анимация полёта + тряска
  - Огонь из выхлопных труб
  - Звук двигателя (растёт с иксом)
  - Случайное мяуканье кота
- Колесо Фортуны:
  - Сегменты с аватарками игроков
  - Таймер 30 сек при 2+ игроках
  - Анимация кручения
- Мины с анимациями
- Профиль, пополнение, демо-режим
- Защита от ботов (проверка Telegram initData)

## Как запустить

1. Залей папку на любой хостинг (GitHub Pages, Vercel, Netlify, свой сервер)
2. В BotFather → Bot Settings → Menu Button / Web App укажи ссылку на index.html
3. Открой бота в Telegram

Для локального теста просто открой `index.html` в браузере.

## Важно

Сейчас всё работает на фронте (баланс в localStorage).  
Для реального запуска нужен бэкенд (ставки, баланс, колесо, кейсы должны считаться на сервере).
